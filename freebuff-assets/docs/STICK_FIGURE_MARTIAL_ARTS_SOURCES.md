# Stick-figure and martial-arts animation sources

A verified shortlist of free/open 2D animation sources for stick figures and
martial-arts combat, compiled on **2026-11-18** for reuse in HTML5 games.

- **22 entries** from **4 sites** scraped: OpenGameArt,
  itch.io, Wikimedia Commons and GitHub search.
- **12 stick-figure packs**, **9 martial-arts character
  packs**, **1 motion-reference set**.
- **8 CC0** entries are redistributable with no obligations — these are the
  only ones eligible for `freebuff-assets/` under its CC0-only policy.
- **8 of the CC0 packs are imported** as 10 assets and 43
  clips; each entry below lists its asset ids.
- **7** are redistributable with conditions (credit and/or
  share-alike), **6** are not.

Machine-readable version (same entries, same counts):
[`manifests/stick-figure-martial-arts-sources.json`](../manifests/stick-figure-martial-arts-sources.json).

## How this was gathered

1. **OpenGameArt** — advanced search over 2D art with 12 keyword queries
   (`stick figure`, `stickman`, `stick man`, `stick fight`, `fighting stick`,
   `martial arts`, `kung fu`, `karate`, `beat em up`, `brawler`, `punch`, `kick`),
   sorted by popularity.
2. **itch.io** — search for `stickman`, `stick figure`, `stick fight`,
   `stickman fight`, `stickman martial arts` and `stickman animation`.
3. **Wikimedia Commons** — the *Stick figures* and *Martial arts animations*
   categories, plus specific stick-fight GIFs.
4. **GitHub** — repository search for stickman animation projects.

Every item page was then opened and its own licence block, author, file list and
animation list were read. A licence appears below only when the item page states
it; "free download" alone was never treated as a licence.

## Caveats

- **"Free" is not a licence.** Five itch.io packs (including two large stickman
  sets) are free to download but state no licence at all; they are marked
  *unclear* above and must not be mirrored.
- **Store mirrors can be stricter than the creator.** The same RGS stick figure
  pack is CC0 on itch.io/OpenGameArt but restricted by GameDev Market's Pro
  Licence; always take it from the creator's own page.
- **Share-alike is viral for art.** Importing CC-BY-SA frames into a CC0 library
  would force the combined work under CC-BY-SA, so those packs are for direct
  game use only.
- **GIFs are not sprite sheets.** The Wikimedia files are motion reference; they
  need slicing into frames before a game can use them.
- Licences were read on 2026-11-18. Re-check the item page before shipping,
  since authors can change terms.
